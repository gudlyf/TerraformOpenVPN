# Changelog

All notable changes to this project are documented here. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

Planned as 2.0.0. A ground-up rewrite. Existing deployments must be destroyed with the old code before you apply this version; see "Upgrading from the old version" in the README.

### Added

- `modules/openvpn-config`: cloud-agnostic PKI, cloud-init and client profile generation, shared by every cloud.
- Reusable modules in `modules/aws`, `modules/azure` and `modules/gcp`, usable from other configurations (`source = "github.com/gudlyf/TerraformOpenVPN//modules/aws"`).
- Multiple clients via `clients`, each with its own certificate and `.ovpn`. Removing a client revokes it through `ccd-exclusive`.
- `vpn_allowed_cidrs` and `ssh_allowed_cidrs` on every cloud (previously only Azure, using a geo-IP lookup).
- Configurable port, protocol (UDP/TCP), client subnet, DNS servers, full or split tunnel and pushed routes.
- Static public IPs on every cloud, so profiles survive VM replacement.
- fail2ban for SSH, enabled automatically when SSH is open.
- `terraform test` suites (mocked providers, no credentials required), a Docker end-to-end test, GitHub Actions CI, pre-commit hooks, Dependabot, issue and PR templates, CONTRIBUTING and SECURITY docs.
- Provider lock files for macOS, Linux and Windows.

### Changed

- Requires Terraform or OpenTofu 1.6+. Providers: AWS 6.x, azurerm 5.x, google 8.x.
- Ubuntu 24.04 LTS with the distribution's OpenVPN 2.6 instead of Ubuntu 16.04/18.04 and the third-party OpenVPN apt repository.
- PKI is generated by Terraform (ECDSA P-256) instead of easy-rsa on the server. `dh none`, `tls-crypt`, TLS 1.2 minimum, AEAD data ciphers, server name pinning on clients.
- Bootstrap is delivered through cloud-init on every cloud. SSH provisioners and `scp` are gone, so SSH is optional and closed by default.
- AWS: dedicated VPC, Graviton `t4g.micro` default (1 GB; 512 MB `t4g.nano` is tight for first-boot upgrades), IMDSv2 required, encrypted gp3 root volume, standard CPU credits.
- Azure: `azurerm_linux_virtual_machine`, Standard SKU static public IP, NSG actually attached to the NIC.
- GCP: Application Default Credentials instead of `account.json`, custom VPC, Shielded VM, `e2-micro` default.
- AzureMktPlace: updated for azurerm 5.x and the `cloudinit` provider; admin password is now a sensitive output; access is controlled with CIDR variables; NSG and route table are attached; optional marketplace terms acceptance.

### Removed

- `cert_details` / `cert_details.sample` (use `cert_subject`).
- Committed `terraform.tfvars` (use `terraform.tfvars.example`).
- The `template` provider, which has no Apple Silicon build.
- Azure's unused `GatewaySubnet`.

### Fixed

- "Invalid reference from destroy provisioner" on Terraform 0.13+ ([#1](https://github.com/gudlyf/TerraformOpenVPN/issues/1)). Client profiles are now `local_sensitive_file` resources that Terraform deletes on destroy.
- OpenVPN failing to start on Azure ([#4](https://github.com/gudlyf/TerraformOpenVPN/issues/4)). easy-rsa 2.x on Ubuntu 18.04 couldn't find an OpenSSL 1.1 config, so `pkitool` generated no keys and the script carried on without them. PKI no longer runs on the server.
- AWS NAT rule missing `-j MASQUERADE`, and Azure NAT covering only a /28 of the /24 client pool.
- Azure NSG never being associated with anything.
- AWS client profiles depending on IMDSv1 to discover the public IP.
- AzureMktPlace image default `access_server_byol`, which no longer has any published versions. The default is now `openvpnas-gen2`.
